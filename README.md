# Welcome to Elderfield 한국어 패치

Steam Windows판용 비공식 한국어 패치입니다. 현재 시험 배포 중이며 게임 전체의 정상 동작은 아직 확인되지 않았습니다.

지원 버전: **v1.0.3b · Steam Build 26243857** (`v1.0.3b-26243857-rc3`). 다른 빌드에는 설치할 수 없습니다.

## 설치

1. 게임을 종료하고 [Releases](https://github.com/yoodong724/elderfield-ko/releases)에서 `v1.0.3b-26243857-rc3` ZIP을 받습니다.
2. ZIP을 `Game.exe`가 있는 게임 폴더에 풉니다.
3. `elderfield-ko/install.cmd`를 실행합니다.

원래 상태로 되돌리려면 `elderfield-ko/restore.cmd`를 실행하세요. 설치기가 원본 파일을 확인하므로 게임이 업데이트됐다면 해당 빌드용 새 패치를 기다려 주세요.

## rc3 변경 사항

- 아이템·퀘스트·대사에서 같은 대상을 가리키는 명칭과 상태 효과 표기를 통일했습니다.
- 인물 말투를 정본에 맞추고 대사·안내·아이템 설명을 다듬었습니다.
- 고유 인물과 장비 이름, 전투 기술 표기를 정리했습니다.
- rc3을 Windows 게임 사본에 설치·실행하고 타이틀, 설정, 난이도, 캐릭터 생성, 상태 및 인벤토리 화면과 복원을 확인했습니다. 상태창의 경험치 문구는 숫자와 붙어 읽기 어렵습니다.
- 수정된 대사·아이템 설명·퀘스트와 게임 업데이트로 바뀐 화면, Molly 장면, 과적 버리기 경고, 창고 한글 IME 및 추가 이미지 전체 표시는 미확인입니다.
