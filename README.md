# Welcome to Elderfield 한국어 패치

Steam Windows판용 비공식 한국어 패치입니다. 현재 시험 배포 중이며 일부 화면의 실제 표시를 확인하고 있습니다.

지원 버전: Steam Build **25459455** (`v25459455-rc1`). 다른 빌드에는 설치할 수 없습니다.

## 설치

1. 게임을 종료하고 [Releases](https://github.com/yoodong724/elderfield-ko/releases)에서 `v25459455-rc1` ZIP을 받습니다.
2. ZIP을 `Game.exe`가 있는 게임 폴더에 풉니다.
3. `elderfield-ko/install.cmd`를 실행합니다.

원래 상태로 되돌리려면 `elderfield-ko/restore.cmd`를 실행하세요. 설치기가 원본 파일을 확인하므로 게임이 업데이트됐다면 해당 빌드용 새 패치를 기다려 주세요.
