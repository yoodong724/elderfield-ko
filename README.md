# Welcome to Elderfield 한국어 패치

Steam Windows판용 비공식 한국어 패치입니다. 현재 시험 배포 중이며 게임 전체의 정상 동작은 아직 확인되지 않았습니다.

지원 버전: **v1.0.3 · Steam Build 26223771** (`v1.0.3-26223771-rc1`). 다른 빌드에는 설치할 수 없습니다.

## 설치

1. 게임을 종료하고 [Releases](https://github.com/yoodong724/elderfield-ko/releases)에서 `v1.0.3-26223771-rc1` ZIP을 받습니다.
2. ZIP을 `Game.exe`가 있는 게임 폴더에 풉니다.
3. `elderfield-ko/install.cmd`를 실행합니다.

원래 상태로 되돌리려면 `elderfield-ko/restore.cmd`를 실행하세요. 설치기가 원본 파일을 확인하므로 게임이 업데이트됐다면 해당 빌드용 새 패치를 기다려 주세요.

## rc1 변경 사항

- 게임 업데이트로 추가된 문구와 기존 문구의 사용 위치를 반영하고, 직업·생활 기술과 모드 메뉴의 안내를 한국어로 갱신했습니다.
- 한국어 이미지 55종과 설치·복원 파일을 새 빌드에 맞춰 갱신했습니다.
- Molly 장면, 과적 상태의 버리기 경고, 창고 한글 IME 및 추가 이미지 전체 표시는 실기 미확인입니다.
