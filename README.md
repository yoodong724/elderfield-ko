# Welcome to Elderfield 한국어 패치

Steam Windows판용 비공식 한국어 패치입니다. 현재 시험 배포 중이며 게임 전체의 정상 동작은 아직 확인되지 않았습니다.

지원 버전: **v1.0.2a · Steam Build 25483278** (`v1.0.2a-25483278-rc4`). 다른 빌드에는 설치할 수 없습니다.

## 설치

1. 게임을 종료하고 [Releases](https://github.com/yoodong724/elderfield-ko/releases)에서 `v1.0.2a-25483278-rc4` ZIP을 받습니다.
2. ZIP을 `Game.exe`가 있는 게임 폴더에 풉니다.
3. `elderfield-ko/install.cmd`를 실행합니다.

원래 상태로 되돌리려면 `elderfield-ko/restore.cmd`를 실행하세요. 설치기가 원본 파일을 확인하므로 게임이 업데이트됐다면 해당 빌드용 새 패치를 기다려 주세요.

## rc3~rc4 변경 사항

- 창고(컨테이너) 아이템 검색에서 OS 한글 IME로 한글 아이템명을 입력해 검색할 수 있습니다. 화면에 보이는 한글 이름과 원문 영어 이름을 모두 검색합니다.
- rc4에서 검색창을 게임의 창 스킨·톤·코너 그래픽 그대로 그리도록 바꾸고 내용을 세로 중앙에 배치했습니다.
- 이 기능은 Windows 한글 IME 환경을 전제로 한 시험 기능이며, 실기 확인 전입니다.
